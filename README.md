# RC Beam Calsheet — ACI 318-19

แอป Streamlit สำหรับออกแบบ/ตรวจสอบคานคอนกรีตเสริมเหล็กหน้าตัดสี่เหลี่ยม ตามมาตรฐาน **ACI 318-19** หน่วย **MKS: cm, kg, kg-m, ksc (kg/cm²)**

## วิธีใช้งาน
```bash
pip install -r requirements.txt
streamlit run app.py
```

## หน่วย
| ข้อมูล | หน่วย |
|---|---|
| ขนาดหน้าตัด, ระยะหุ้ม, ระยะเรียงเหล็ก | cm |
| f'c, fy, fyt | ksc (kg/cm²) — SR24 = 2,400, SD30 = 3,000, SD40 = 4,000, SD50 = 5,000 |
| น้ำหนักบรรทุก | kg/m |
| Mu / Vu | kg-m / kg |
| พื้นที่เหล็ก | cm² |

## ค่าสัมประสิทธิ์ (ค่าเริ่มต้น: วสท.)
ใช้ค่าปัดในหน่วย kg-cm ตามแนวทาง วสท. (เลือกเปลี่ยนเป็นค่าแปลงตรงจาก SI ได้ใน sidebar)

แกนคำนวณ (`aci318.py`) ทำงานในหน่วย SI โดยค่าสัมประสิทธิ์ วสท. ถูกแปลงกลับแบบตรงตัว ผลลัพธ์จึงเท่ากับการคำนวณมือด้วยสมการ kg-cm ข้างต้นทุกประการ (1 kg = 9.80665 N)
