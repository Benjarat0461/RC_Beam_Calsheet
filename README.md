# RC Beam Calsheet — ACI 318-19

แอป Streamlit สำหรับออกแบบ/ตรวจสอบคานคอนกรีตเสริมเหล็กหน้าตัดสี่เหลี่ยม ตามมาตรฐาน **ACI 318-19** หน่วย **MKS: cm, kg, kg-m, ksc (kg/cm²)**

## วิธีใช้งาน
```bash
pip install -r requirements.txt
streamlit run app.py
```

## หน่วย
| ข้อมูล | หน่วย |
|---|---|
| ขนาดหน้าตัด, ระยะหุ้ม, ระยะเรียงเหล็ก | cm |
| f'c, fy, fyt | ksc (kg/cm²) — SR24 = 2,400, SD30 = 3,000, SD40 = 4,000, SD50 = 5,000 |
| น้ำหนักบรรทุก | kg/m |
| Mu / Vu | kg-m / kg |
| พื้นที่เหล็ก | cm² |

แกนคำนวณ (`aci318.py`) ใช้สมการ ACI 318-19 ฉบับ SI และแปลงหน่วยแบบตรงตัวที่ขอบเขตข้อมูลเข้า/ออก (1 kg = 9.80665 N)
ค่าสัมประสิทธิ์ที่แสดงจึงเป็นค่าแปลงที่แน่นอน เช่น Vc = 0.54λ√f'c·bw·d, As,min = max(0.80√f'c, 14.3)·b·d/fy
