# RC Beam Calsheet — ACI 318-19

แอป Streamlit สำหรับออกแบบ/ตรวจสอบคานคอนกรีตเสริมเหล็กหน้าตัดสี่เหลี่ยม ตามมาตรฐาน **ACI 318-19** (หน่วย SI)

## วิธีใช้งาน
```bash
pip install -r requirements.txt
streamlit run app.py
```
